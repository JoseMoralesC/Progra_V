## Reproducción y límites

Ejecuté .NET con `dotnet test PrograV.sln --no-restore --logger trx`, dirigiendo los resultados a este directorio. Para Java utilicé el `mvnw.cmd` de Usuario sobre el `pom.xml` raíz, `-fae -pl NuevoAvatar.Usuario,NuevoAvatar.Institucion,NuevoAvatar.Profesor,NuevoAvatar.Carrera,NuevoAvatar.Expediente,NuevoAvatar.Prematricula,NuevoAvatar.Notas,NuevoAvatar.Notificacion -am test`. Las variables `NOTAS_SQL_TEST_URL`, `NOTAS_SQL_TEST_USER` y `NOTAS_SQL_TEST_PASSWORD` se prepararon en memoria desde el entorno autorizado y no se copiaron aquí. La prueba SQL solo adquiere un bloqueo temporal y termina en rollback.

En cada cliente ejecuté sus comandos de compilación y, cuando existe, `npm.cmd test`. En el cliente principal ejecuté además `npm.cmd run lint`. Para completar el diagnóstico de la suite principal utilicé `node node_modules/@playwright/test/cli.js test --reporter=json --workers=3 --timeout=10000 --global-timeout=240000`. Después confirmé todos los casos con `node node_modules/@playwright/test/cli.js test --reporter=json --workers=3 --global-timeout=360000`, conservando el tiempo normal de treinta segundos por caso. El primer intento había usado un límite global de 150 segundos con la configuración original. Conservo el resumen de los tres resultados y cuento solo la confirmación. El ajuste de trabajadores y tiempo fue de ejecución, sin editar las pruebas.

El diagnóstico estudiantil utilizó un guion temporal, retirado al organizar la entrega. Inició y cerró Vite en el puerto 4176, cerró la bienvenida mediante su botón y utilizó el botón actual de guardado. Mantiene las expectativas funcionales de las historias. Sus respuestas controladas incluyen TAMPAG=2, dieciséis solicitudes, falta de vínculo, vacío y dependencia caída.

Para revisar límites SQL/JPA conservé el comprobador existente y dirigí su salida a este directorio mediante una sustitución en memoria del destino; no sobrescribí el informe anterior. Las consultas adicionales fueron únicamente SELECT y cerraron sus conexiones sin cambios.

Durante la consulta de puertos del corte inicial el entorno estaba detenido. En la actualización sí lo inicié y agregué [156 comprobaciones reales: 144 aprobadas y 12 fallidas](recorrido-real/resultados-conservados.md#resultados-reales), separadas de los 576 casos locales. El conjunto contado reúne 692 aprobadas y 40 fallidas de 732, sin duplicar el contenedor de navegador de Notas. Las evidencias previas del equipo conservan su procedencia y no se suman otra vez. No repetí un envío SMTP.
