# Contenidos académicos sintéticos

Oferta de simulación; no representa planes oficiales ni acreditados del CUC. Cada carrera tiene 24 materias distintas, organizadas en seis niveles de cuatro materias.

El modelo existente almacena nombre y nivel, pero no tiene una columna de contenidos. Esta guía complementa los datos sin modificar la estructura.
